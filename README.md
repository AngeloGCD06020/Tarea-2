# LOL SUPERMAN — Tarea 08: Model Info

Proyecto de realidad aumentada en Unity **6000.3.14f1**, actualizado en la rama **main**.

En Unity Hub, agrega la subcarpeta **`LOL SUPERMAN`**. Después abre la escena **`Assets/Scenes/Tarea 08.unity`**.

La tarea incluye el panel con nombre, descripción, categoría, nivel e icono; tres ScriptableObjects para Greninja, Paletas y Miku; selección por raycast y reinicio de la ficha al perder el seguimiento.
